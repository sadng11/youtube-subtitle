# افزونه مترجم هوشمند زیرنویس یوتیوب به فارسی (YouTube Persian Subtitle Translator)

افزونه گوگل کروم با معماری مدرن **Manifest V3** برای استخراج خودکار زیرنویس انگلیسی ویدیوهای یوتیوب، ترجمه روان به زبان فارسی با استفاده از مدل‌های زبانی هوش مصنوعی (Google Gemini یا OpenAI ChatGPT)، و نمایش همگام‌سازی‌شده (Synced) روی پلیر یوتیوب.

---

## ویژگی‌های اصلی

- 🚀 **استخراج مستقیم زیرنویس (TimedText):** بدون نیاز به کلید YouTube Data API و پشتیبانی از زیرنویس‌های دستی و خودکار (Auto-generated).
- 🤖 **پشتیبانی از ارائه‌دهندگان هوش مصنوعی:**
  - **Google Gemini:** مدل‌های `gemini-1.5-flash`، `gemini-2.0-flash` و `gemini-1.5-pro` (سریع با سهمیه رایگان).
  - **OpenAI:** مدل‌های `gpt-4o-mini` و `gpt-4o`.
  - **مسیر سفارشی (Custom Route):** سازگار با ساختار استاندارد OpenAI برای اتصال به سرویس‌های ابری یا محلی از جمله Ollama، DeepSeek، OpenRouter، Groq، vLLM، LM Studio و پروکسی‌های اختصاصی (با دریافت `base_url`، `key` و `model`).
- 🇮🇷 **تایپوگرافی فارسی زیبا و خوانا (RTL):** طراحی اختصاصی با فونت وزیرمتن و پس‌زمینه نیمه‌شفاف برای خوانایی روی هر پس‌زمینه‌ای.
- 🌐 **حالت دوزبانه (Bilingual):** نمایش همزمان متن اصلی انگلیسی (بالا) و ترجمه فارسی (پایین) برای تقویت زبان انگلیسی.
- ⚡ **سیستم کش محلی (Local Cache):** ذخیره نتایج ترجمه‌شده در مرورگر برای جلوگیری از مصرف مجدد توکن در تماشای دوباره ویدیو.
- 🎛️ **شروع ترجمه به صورت اختیاری و با دکمه (کنترل کامل هزینه):** ترجمه به صورت خودکار شروع نمی‌شود تا توکن ناخواسته مصرف نشود و بتوانید ویدیو را به زبان اصلی ببینید. با فشردن دکمه «✨ ترجمه هوشمند» روی پلیر یا پنجره افزونه، ترجمه آغاز می‌گردد.
- 🔘 **دکمه دسترسی سریع روی پلیر یوتیوب:** امکان خاموش/روشن کردن آنی زیرنویس فارسی یا تماشای زیرنویس اصلی مستقیماً از نوار کنترل پلیر یوتیوب.
- 📱 **پشتیبانی کامل از حالت فول‌اسکرین (Fullscreen):** مقیاس‌پذیری خودکار اندازه متن هنگام تمام‌صفحه کردن ویدیو.

## نحوه نصب در گوگل کروم (Install Unpacked)

۱. مرورگر **Google Chrome** را باز کنید و وارد آدرس زیر شوید:
   ```text
   chrome://extensions
   ```
۲. در گوشه بالا سمت راست، گزینه **Developer mode** را فعال کنید.
۳. روی دکمه **Load unpacked** (بارگذاری افزونه غیر بسته‌بندی شده) کلیک کنید.
۴. پوشه پروژه (`/data/js/youytube-translate`) را انتخاب کنید.
۵. افزونه به لیست افزونه‌های شما اضافه خواهد شد.

---

## نحوه راه‌اندازی و استفاده

۱. روی آیکون افزونه در نوار ابزار کروم کلیک کنید تا منوی تنظیمات باز شود.
۲. ارائه‌دهنده مورد نظر خود را انتخاب کنید:
   - برای **Google Gemini**: کلید رایگان خود را از [Google AI Studio](https://aistudio.google.com/app/apikey) دریافت کرده و وارد کنید.
   - برای **OpenAI**: کلید خود را از [OpenAI API Keys](https://platform.openai.com/api-keys) وارد کنید.
   - برای **مسیر سفارشی (Custom Route)**:
     - **Base URL:** آدرس پایه مانند `https://api.deepseek.com/v1` یا `http://localhost:11434/v1` یا `https://openrouter.ai/api/v1`
     - **API Key:** کلید احراز هویت (در صورت استفاده از سرورهای لوکال مانند Ollama می‌تواند خالی بماند).
     - **Model:** شناسه مدل (مانند `deepseek-chat`، `llama3`، `mistral` و ...).
۳. دکمه **تست اتصال** را برای اطمینان از برقراری ارتباط بزنید و سپس **ذخیره تنظیمات** را انتخاب کنید.
۴. هر ویدیوی یوتیوب که دارای زیرنویس انگلیسی است را باز کنید:
   - افزونه زیرنویس را شناسایی کرده و اعلان وضعیت ترجمه نمایش داده می‌شود.
   - پس از چند ثانیه، زیرنویس فارسی هماهنگ با ویدیو پخش می‌شود!

## ساختار فایل‌ها

```text
├── manifest.json            # فایل کانفیگ افزونه Manifest V3
├── background.js            # سرویس‌ورکر پس‌زمینه برای برقراری ارتباط با LLM و کش
├── content/
│   ├── content.js           # اسکریپت اصلی تزریق به یوتیوب و همگام‌سازی زمان
│   ├── page-script.js       # اسکریپت دسترسی به کانتکست صفحه یوتیوب
│   └── overlay.css          # استایل‌های لایه زیرنویس، فونت و انیمیشن‌ها
├── popup/
│   ├── popup.html           # منوی پاپ‌آپ تنظیمات
│   ├── popup.js             # منطق پاپ‌آپ و مدیریت تنظیمات
│   └── popup.css            # استایل مدرن دارک‌مود پاپ‌آپ
└── icons/
    ├── icon-16.png
    ├── icon-48.png
    └── icon-128.png
```
